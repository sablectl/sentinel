# Changelog

Notable changes to Sentinel are recorded here.

## [1.0.0] - 2026-11-15

### Added

- Initial local-first ingestion, SQLite storage, detection, alert lifecycle and authenticated dashboard implementation.
- CLI commands for health checks, source imports, source status, rule management, alert triage and JSON/CSV export.
- Unit and integration test suites, documentation, a performance procedure and CI configuration.
